How to connect

Any agent in this project can report:

glass register --name builder --model MODEL \
  --task "what it is doing"
glass event --kind tool.call \
  --action read --target path/to/file
glass heartbeat --task "still working"

Harnesses with a shell can call these directly; the OpenCode plugin does it automatically. The server binds to 127.0.0.1 only and shows prompts and paths, so never expose it.
